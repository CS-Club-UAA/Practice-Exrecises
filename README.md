# Practice-Exrecises
This is a repository to reccord the practices that we do as a club. There will be ton of short exercises of varying difficulty, varying languages,  and of course their solutions.

## Contributions

If you have any good exercises, please feel free to add them. But create a proper folder for the language is in and create 3 elements:
 - README.md  -> Explaining what the problem is and what the user should do to try on solving the problem
 - The code file
 - The solution

## Saving your solution

You may add your solution in the same folder of the exercise just create a different file use your username + Solution. For example:
- Arthur's Solution.py 

As developers is always great to learn from each other, learning never stops!
